# 🎓 AI Face Recognition Attendance System

### Smart Attendance Management using Artificial Intelligence & Computer Vision

---

# 📌 Overview

AI Face Recognition Attendance System is an intelligent attendance management solution developed using Python, OpenCV, and Machine Learning.

The system automatically detects and recognizes faces through a webcam and marks attendance in real-time.

---

# 🚀 Features

## 👤 Face Recognition
- Real-time face detection
- AI-based face recognition
- Unknown face detection

---

## 📝 Automatic Attendance
- Marks attendance automatically
- Stores attendance records
- Prevents duplicate entries

---

## ⏰ Smart Class Scheduling
- Automatic attendance based on class routine
- Webcam starts automatically before class

---

## 📊 Attendance Reports
- Present/Absent tracking
- Attendance percentage calculation
- CSV based attendance records

---

## 🖥 User-Friendly System
- Easy to use
- Real-time webcam interface
- Live attendance monitoring

---

# 🛠 Technologies Used

- NumPy
